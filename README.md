# Nexora — Your Discord Server, Upgraded

Nexora is a feature-packed Discord bot built to make communities more fun, interactive, and easier to manage. From moderation and server utilities to custom interactive experiences, Nexora brings a lot more than basic commands.

> **Prefix:** `n!`  
> **Help menu:** `n!help` or `/help`  
> **Invite Nexora:** [Add Nexora to your server](https://discord.com/oauth2/authorize?client_id=1167464602620145808)

---

## ✨ Standout Features

### 🎲 Random Avatar Roulette
Discover someone new in your server with **Random Avatar**. It picks a random member and displays their high-resolution avatar, with interactive buttons to:
- Roll another random member
- Switch between their avatar and profile details
- Open high-resolution avatar formats
- Dismiss the card when you're done

### 🎧 Live Spotify Showcase
See what someone is listening to through an interactive Spotify card featuring:
- Album art, track title, artist, and album
- Live playback progress and remaining time
- A button to open the track in Spotify
- Refresh and lyrics-search shortcuts

Spotify details depend on the member sharing their activity with Discord.

### 🖼️ Interactive Avatar & Profile Viewer
More than a basic avatar command. Explore high-resolution profile media with interactive views for available avatar variants, banners, profile details, and direct image links.

### 💤 Smart AFK
Set an AFK status and let Nexora handle mention notifications while you're away. Available options depend on the server's configuration.

### 🧭 Interactive Help Menu
Find commands through category browsing, command details, and search instead of digging through a giant command list.

## 🚀 Getting Started

1. [Invite Nexora](https://discord.com/oauth2/authorize?client_id=1167464602620145808) to your Discord server.
2. Make sure it has the permissions needed for the features you want to use.
3. Run **`n!help`** or **`/help`** to explore the available commands.

**Prefix commands** use `n!`. Slash commands are available where registered with Discord. Some features open interactive buttons, menus, or cards after you run them.
